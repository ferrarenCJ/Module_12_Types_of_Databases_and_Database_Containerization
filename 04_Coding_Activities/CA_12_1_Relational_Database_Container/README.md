# Coding Activity 12.1: Modify a Relational Database in a Container

## Objective

The objective of this activity is to learn how to interact with a relational database using Python and MySQL. This activity demonstrates how to connect to a MySQL database, create a database, insert records, query data, and perform database operations using Python scripts.

---

## Learning Outcomes

After completing this activity, I was able to:

- Connect Python to a MySQL database.
- Use the MySQL Connector for Python.
- Create a database programmatically.
- Insert records into a relational database.
- Query data from a database.
- View available databases from Python.
- Understand how database drivers enable communication between applications and databases.

---

## Technologies Used

- Python
- MySQL
- MySQL Connector for Python
- Visual Studio Code
- Docker (Container Environment)
