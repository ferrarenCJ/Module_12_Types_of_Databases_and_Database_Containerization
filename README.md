# Module 12 - Types of Databases and Database Containerization

## Module Overview

Module 12 explores the different types of databases used in modern data engineering and introduces database containerization concepts. The module covers relational and non-relational databases, database management systems, SQL and NoSQL technologies, and the use of Docker containers to deploy and manage database environments.
