# Module 12: Types of Databases and Database Containerization

## Overview

This module explores several common database technologies used in modern data engineering environments and introduces database containerization. Students learn how to perform CRUD (Create, Read, Update, Delete) operations on relational and NoSQL databases, deploy databases within containers, and evaluate appropriate use cases for different database architectures.

The module covers:

- Relational Databases (MySQL)
- Database Containerization
- MongoDB (Document Database)
- Redis (Key-Value Database)
- Cassandra (Distributed Scalable Database)
- Firebase (Serverless Cloud Database)
- Benefits of Serverless Architecture
- Database Selection and Real-World Use Cases

---

## Learning Outcomes

Upon completion of this module, students will be able to:

1. Describe applications of various database types.
2. Identify key concepts related to database containerization.
3. Update and delete data in different containerized databases.
4. Explain key concepts associated with relational and NoSQL databases.

## Topics Covered

### Relational Databases
- Relational database concepts
- Tables, rows, and columns
- SQL fundamentals
- CRUD operations using MySQL

### Database Containerization
- Introduction to containers
- Running databases within containers
- Querying containerized databases
- Database portability and deployment

### MongoDB
- Document-oriented database
- JSON/BSON document storage
- Flexible schemas
- CRUD operations in MongoDB

### Redis
- Key-value database architecture
- In-memory storage
- High-performance lookups
- Caching and session management

### Cassandra
- Distributed NoSQL database
- Horizontal scalability
- Fault tolerance
- High availability architecture

### Firebase
- Serverless cloud database
- Real-time synchronization
- Managed database services
- Cloud-native application support

## Key Takeaways

Modern data engineering requires selecting the right database based on data structure, scalability requirements, performance needs, and operational constraints. This module demonstrates how relational, document, key-value, distributed, and serverless databases address different business and technical challenges while introducing containerized deployment strategies commonly used in industry.
