# Module 12 Videos
## Types of Databases and Database Containerization

This folder contains notes, summaries, transcripts, and supporting materials related to the videos covered in Module 12.

The videos in this module introduced students to several database technologies commonly used in modern data engineering environments, including relational databases, NoSQL databases, distributed databases, serverless cloud databases, and database containerization using Docker.

---

# Learning Objectives

Through the Module 12 videos, students learned how to:

- Understand relational database concepts.
- Perform CRUD operations using MySQL.
- Deploy databases using Docker containers.
- Work with document-oriented databases.
- Explore key-value database architectures.
- Understand distributed database systems.
- Configure and use serverless cloud databases.
- Compare the strengths and use cases of different database technologies.

# Key Takeaways

### Relational Databases

- Structured schema
- SQL support
- ACID transactions

### MongoDB

- Flexible document storage
- JSON-based structure
- Horizontal scalability

### Redis

- High-speed key-value access
- In-memory processing
- Simple architecture

### Cassandra

- Distributed design
- Fault tolerance
- High availability

### Firebase

- Serverless cloud architecture
- Realtime data synchronization
- Managed infrastructure

### Docker

- Portable deployments
- Consistent environments
- Simplified database management
