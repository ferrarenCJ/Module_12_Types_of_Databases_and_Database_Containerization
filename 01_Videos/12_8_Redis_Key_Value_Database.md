# Video 12.8: Redis: A Key-Value Database

## Overview

This lesson introduces Redis, an in-memory key-value database designed for extremely fast data access and retrieval. Unlike relational databases and document databases, Redis stores information using simple key-value pairs, making it ideal for caching, session management, and real-time applications.

Dr. Sanchez demonstrates:

- What Redis is
- How key-value databases work
- Running Redis in a Docker container
- Connecting to Redis from Python
- Reading and writing data using Redis

## What Is Redis?

Redis stands for:

```text
REmote DIctionary Server
```

Redis is an:

- In-memory database
- Key-value store
- NoSQL database
- High-performance data platform

Unlike relational databases that use tables or MongoDB that uses documents, Redis stores information as key-value pairs.
