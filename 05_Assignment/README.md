# Final Assignment 12.1: Types of Databases and Database Containerization

## Overview

This assignment demonstrates the concepts learned throughout Module 12, including relational databases, database containerization, key-value databases, and serverless cloud databases. The assignment consists of three technical components:

1. MySQL relational database creation and containerization
2. Redis key-value database operations using Docker
3. Firebase serverless cloud database integration using Python

The assignment provides hands-on experience with database creation, data storage, retrieval operations, Docker containerization, and cloud-hosted database services.
