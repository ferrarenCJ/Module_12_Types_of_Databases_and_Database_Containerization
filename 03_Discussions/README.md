# Module 12 Discussions
## Types of Databases and Database Containerization

This folder contains discussion activities completed during Module 12. The discussions focused on database technologies, database containerization, serverless cloud databases, and the sharing of learning resources and best practices within the data engineering community.

---

# Purpose

The discussion activities were designed to:

- Encourage collaboration among learners.
- Apply database concepts to real-world scenarios.
- Explore practical use cases for different database technologies.
- Share resources, tips, and troubleshooting techniques.
- Develop critical thinking about database selection and architecture.
