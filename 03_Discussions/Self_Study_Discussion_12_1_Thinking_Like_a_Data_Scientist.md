# Self-Study Discussion 12.1: Thinking Like a Data Scientist: Types of Databases and Database Containerization

One resource that helped me throughout this module was the DockerLabs Docker Cheat Sheet:

https://dockerlabs.collabnix.com/docker/cheatsheet/

This cheat sheet provides a quick reference for the most common Docker commands, including creating containers, viewing running containers, stopping containers, and accessing containerized applications. During the MySQL and Redis activities, I frequently used it to verify command syntax when creating and managing database containers. Having a concise reference available saved time and helped me better understand how containerization works in practice.

Another resource I found useful was the official Docker documentation:

https://docs.docker.com/

The documentation helped me understand port mapping, container networking, and container lifecycle management. This was especially helpful when configuring MySQL on port 3300 and Redis on port 6379. The examples and explanations provided a deeper understanding of why containers are frequently used in modern data engineering environments.

For Firebase and the serverless cloud database activity, I found the Firebase documentation extremely valuable:

https://firebase.google.com/docs

The Firebase guides provided clear instructions for creating projects, generating service account credentials, creating Realtime Databases, and connecting Python applications using the Firebase Admin SDK. The troubleshooting sections were particularly useful when diagnosing connectivity and authentication issues.

One personal tip I would recommend is creating a small collection of notes and screenshots while working through each activity. I organized my module files in GitHub and kept screenshots, code samples, and markdown notes together. This made it much easier to troubleshoot issues, document my assignments, and revisit concepts when moving between MySQL, Redis, and Firebase.

Overall, the combination of Docker documentation, Firebase documentation, and personal notes provided a solid foundation for understanding both database technologies and containerized deployments in this module.
