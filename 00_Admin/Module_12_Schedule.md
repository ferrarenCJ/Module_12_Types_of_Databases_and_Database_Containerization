# Module 12: Types of Databases and Database Containerization

## Module Status

**Status:** Nearly Complete ✅

This module explored multiple database technologies and deployment methods used in modern data engineering. Activities included working with relational databases, containerized databases, NoSQL databases, distributed databases, and serverless cloud databases. Docker was used to deploy database containers, while Firebase provided hands-on experience with a serverless cloud database platform.
