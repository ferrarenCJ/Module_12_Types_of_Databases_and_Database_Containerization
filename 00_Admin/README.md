# Module 12: Types of Databases and Database Containerization

## Overview

Module 12 introduces several modern database technologies and deployment approaches commonly used in data engineering. The module explores relational databases, database containerization, document-oriented databases, key-value databases, distributed scalable databases, and serverless cloud databases.

Students gain hands-on experience creating, querying, updating, and managing data using multiple database platforms including MySQL, MongoDB, Redis, Cassandra, and Firebase. The module also introduces Docker containerization and demonstrates how databases can be deployed and managed within containerized environments.

---

## Learning Outcomes

By completing this module, students will be able to:

- Identify key concepts related to database containerization.
- Create, read, update, and delete data using different database technologies.
- Describe applications of various database types.
- Compare relational and NoSQL databases.
- Deploy and interact with containerized database environments.
- Work with serverless cloud database technologies.

## Key Takeaways

- Relational databases use structured tables and SQL.
- MongoDB stores flexible document-based data.
- Redis provides extremely fast key-value operations.
- Cassandra offers scalability and fault tolerance through distributed architecture.
- Firebase enables serverless cloud database development with minimal infrastructure management.
- Docker simplifies database deployment through containerization.
- Different database technologies are optimized for different use cases and business requirements.
