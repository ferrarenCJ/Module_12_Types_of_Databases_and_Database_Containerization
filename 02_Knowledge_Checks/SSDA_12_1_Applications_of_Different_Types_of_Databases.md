# Database Types Reviewed

## MySQL

### Type

```text
Relational Database
```

### Strengths

- Structured data
- SQL support
- ACID transactions

### Typical Use Cases

- Financial systems
- Inventory management
- Enterprise applications

---

## MongoDB

### Type

```text
Document Database
```

### Strengths

- Flexible schema
- JSON-style documents

### Typical Use Cases

- Web applications
- Content management systems

---

## Redis

### Type

```text
Key-Value Database
```

### Strengths

- High performance
- In-memory storage
- Fast retrieval

### Typical Use Cases

- Caching
- Session management
- Real-time applications

---

## Cassandra

### Type

```text
Distributed Scalable Database
```

### Strengths

- Horizontal scaling
- High availability
- Fault tolerance

### Typical Use Cases

- IoT systems
- Telecommunications
- Large-scale analytics

---

## Firebase

### Type

```text
Serverless Cloud Database
```

### Strengths

- Real-time synchronization
- Automatic scaling
- Managed infrastructure

### Typical Use Cases

- Mobile applications
- Web applications
- Real-time collaboration
- Field data collection systems

---

# Key Takeaways

- MySQL supports CRUD operations through SQL and Python database drivers.
- Docker containers simplify database deployment and management.
- MongoDB is a document-oriented database.
- Redis is a key-value database optimized for high-speed operations.
- Cassandra is a distributed scalable database designed for high availability.
- Firebase is a serverless cloud database managed by Google.
- Python can be used to interact with Firebase databases through the Firebase Admin SDK.
- Different database types are designed to solve different business and technical requirements.
