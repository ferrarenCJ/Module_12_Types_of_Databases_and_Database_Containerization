# Important Terms

### CRUD

```text
Create
Read
Update
Delete
```

### Driver

A Python library used to connect an application to a database.

### Container

An isolated runtime environment used to deploy applications and databases.

### Image

A template used to create containers.

### Collection

MongoDB's equivalent of a relational database table.

### Document

MongoDB's equivalent of a database record.

### Keyspace

Cassandra's equivalent of a database.

### Node

A server containing data within a Cassandra cluster.

### Cluster

A collection of Cassandra nodes operating together.

### Serverless

A cloud architecture where infrastructure management is handled by the cloud provider.
